Strategy A — VICReg (V + C only)

L = L_jepa + λ_v·V(z_price) + λ_c·C(z_price) V = mean_d [ max(0, γ − std(z[:,d])) ] C = Σ_{i≠j} cov(z)²_{ij} / d λ_v=25.0 λ_c=1.0 γ=1.0
Invariance term intentionally dropped — it conflicts with JEPA's temporal prediction objective. Context and target are different time slices, not augmentations.

Strategy B — Soft Codebook

z_codebook = Σ_k softmax(−||z − e_k||²)_k · e_k L += λ_commit · ||z_price − sg(z_codebook)||² K=64–512 vectors sg() = stop-gradient

Init codebook with k-means on z_price from frozen forward pass. Monitor utilization — if <50% of vectors active per batch, reduce λ_commit.

Bonus: codebook assignments = interpretable market regime distribution.

Conditioning Signals (by horizon)

1-DAY TARGETS — fast signals dominate

Fast (intraday)

  • Order flow imbalance
  • Signed trade flow
  • Kyle's λ estimates
  • Quote depth, bid-ask spread
  • Trade size distribution
MEDIUM TARGETS

Medium (earnings cycle)

  • Earnings call transcripts
  • Analyst estimate revisions
  • 13F positioning changes
  • Short interest
1-MONTH TARGETS — slow signals dominate

Slow (daily–weekly)

  • IV surface, put-call skew
  • CDX credit spreads
  • Currency carry, commodity curves
  • Citi Economic Surprise Index
  • PMI beat/miss sequences

Do not use raw ticker symbols as conditioning. Embed company characteristics (sector, size, leverage, business model) instead.
Gating: implement a learned gating layer that takes prediction horizon as a scalar input to weight fast vs slow signals.
